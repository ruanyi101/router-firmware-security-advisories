Vendor: TRENDnet
Product: TEW-657BRM
Version or Commit: 1.00.1
Vulnerability: Out-of-bounds Read
Submission recommendation: HOLD until practical service-availability impact is substantiated.

Description:
An out-of-bounds read condition was identified in the authenticated configuration-restore handler /usr/sbin/restore_config.cgi of TRENDnet TEW-657BRM firmware 1.00.1 (hardware v1.0R). After locating a multipart Content-Disposition marker, the handler scans for the end of multipart headers using a bytewise loop that does not adequately verify the input-buffer boundary. An incomplete multipart body can cause an out-of-range load. The original research reports a SIGSEGV in the CGI process and a debugger location in the scanning loop during re-hosted QEMU-MIPS testing. The same report states that valid or controlled malformed inputs returned normally. The documented outcome is a CGI worker crash, not a confirmed whole-router outage, arbitrary read disclosure, or code execution. Authentication is required for this upload handler. CWE-125 applies. The source draft proposes CVSS v3.1 3.5 (AV:A/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:L), conditional on confirming meaningful availability impact. Hardware reproduction and vendor notification status remain unverified.
