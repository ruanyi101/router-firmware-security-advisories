An out-of-bounds write vulnerability was identified in TRENDnet TEW-657BRM firmware 1.00.1 (hardware revision v1.0R). The embedded mini_httpd HTTP server constructs a redirect URL for certain request paths containing ".htm" using an unbounded sprintf into a fixed-size global buffer before its HTTP Basic authentication check. An oversized unauthenticated request path can overwrite adjacent global data. The supplied research documents a crash, program-counter control (PC=0x23232323), and a benign test-payload execution in a re-hosted QEMU-MIPS environment. The web server is reported to run as root, so exploitation may permit unauthorized code execution where the web management interface is reachable. These findings have not been independently verified on physical hardware. This bug affects mini_httpd pre-authentication request parsing and is distinct from previously published setup.cgi vulnerabilities. CWE-787 / CWE-120. Vendor notification status and CVE assignment must be verified by the submitter.
